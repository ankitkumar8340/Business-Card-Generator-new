# Business Card Generator

A full-stack web application that allows users to create, customize, preview, and download professional business cards. The application provides a simple and user-friendly interface for designing modern digital business cards with real-time updates.

## Features

* Create professional business cards
* Live preview while editing
* Upload profile images
* Customize personal and business details
* Responsive design for desktop and mobile
* Download generated business cards
* Fast and modern user interface

## Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* JavaScript

### Backend

* Node.js
* Express.js

## Project Structure

```
Business-Card-Generator-new
│
├── client/      # React Frontend
├── server/      # Express Backend
└── README.md
```

## Getting Started

### Clone the repository

```bash
git clone https://github.com/ankitkumar8340/Business-Card-Generator-new.git
```

### Navigate to the project

```bash
cd Business-Card-Generator-new
```

### Install frontend dependencies

```bash
cd client
npm install
npm run dev
```

### Install backend dependencies

```bash
cd ../server
npm install
npm start
```
