# 📖 Overview

Business Card Generator is a modern web application that allows users to create professional business cards in just a few clicks.

Simply enter your personal or business information, customize the appearance, preview the card in real time, and download a high-quality business card ready for printing or sharing digitally.

The application is designed with a clean UI, responsive layout, and fast performance.

- 🎨 Beautiful and modern UI

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ankitkumar8340/Business-Card-Generator-new.git
```

Move into the project

```bash
cd Business-Card-Generator-new
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
